# Profile identity assets

The profile uses **Studio + Ardósia + Harpia**, with **Design. Build. Question.**

- `profile-banner.svg`: self-contained banner, 1200 × 280. Source Sans 3 lettering is converted to vector outlines so rendering does not depend on external fonts. Accessible title, description, and README alt text carry the wording.
- `harpia.svg`: original harpy-eagle mark, also used for the personal site's favicon.
- `fonts/SourceSans3-OFL.txt`: license for Source Sans 3, by Adobe. [Font source](https://github.com/google/fonts/tree/main/ofl/sourcesans3).

| Role | Color |
| --- | --- |
| Paper | `#F4F5F6` |
| Main text | `#2C3541` |
| Secondary text | `#596675` |
| Accent | `#455F78` |
| Surface | `#E6EAEE` |
| Rule | `#B8C2CC` |

Keep the banner's wording in its title/description and the README alt text when changing the vector lettering. Use the same Harpia geometry across the profile and website.
